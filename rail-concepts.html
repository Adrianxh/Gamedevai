Two next steps for the "On this page" rail

Both keep the current Docs Split layout and change only the rail. Concept A stays light and editorial; concept B pulls the terminal navbar into the page. Both are shown on your Unity MCP guide's structure.

A

Progress Rail

The rail becomes a reading tracker. Each section is numbered and shows its reading time. The line beside it fills green as you read, and finished sections get struck through. A "% read" counter and a back-to-top link sit at the bottom.

Feels like
A course outline: calm and editorial, close to what you have now
Engagement
Visible progress pushes readers to finish long guides; per-section minutes set expectations
Build
CSS + small script changes; reading time per section from PHP
