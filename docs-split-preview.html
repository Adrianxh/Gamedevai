This guide connects Claude Code to the Unity editor through the Model Context Protocol, so you can ask for changes in plain English and watch them happen in your project.

  • Unity 6
  • Claude Code
  • Node.js 20+

What Unity MCP actually does#

Unity talks to Claude Code through a small MCP server that runs inside the editor. Once it is connected, Claude can read your scene hierarchy, create GameObjects, edit scripts and run tests without you copying anything back and forth.
